╔════════════════════════════════════════════════════════════════════════════╗
║                     REQUISITOS PREVIOS (UNA SOLA VEZ)                     ║
╚════════════════════════════════════════════════════════════════════════════╝

1. INSTALAR CMAKE
   • Descarga: https://cmake.org/download/
   • Elige: Windows (ZIP)
   • Descomprime en C:\cmake
   • Agrega a PATH:
     - Variables de entorno → Busca "PATH"
     - Nuevo: C:\cmake\bin
     - Aplica cambios

2. INSTALAR VISUAL STUDIO 2022 BUILD TOOLS
   • Descarga: https://visualstudio.microsoft.com/downloads/
   • Elige: "Build Tools for Visual Studio 2022"
   • Instala con: "Desktop development with C++"

3. VERIFICAR INSTALACIÓN
   Abre PowerShell y ejecuta:
   
   $ cmake --version
   (debería mostrar versión de CMake)
   
   $ where cmake
   (debería mostrar ruta de CMake)

PROBLEMA: "cmake: comando no encontrado"
─────────────────────────────────────────
✓ CMake no está en PATH
✓ Solución:
  1. Instala CMake desde https://cmake.org/download/
  2. Marca opción: "Add CMake to system PATH"
  3. Reinicia PowerShell

PROBLEMA: "Visual Studio no encontrado"
──────────────────────────────────────────
✓ Build Tools no instalado
✓ Solución:
  1. Instala Visual Studio 2022 Build Tools
  2. Elige: Desktop development with C++
  3. Reinicia la compilación

PROBLEMA: "InventoryOptimizer.dll no se creó"
───────────────────────────────────────────────
✓ Error en la compilación
✓ Solución:
  1. Verifica los logs en la ventana de compilación
  2. Asegúrate de tener espacio en disco (> 1GB)
  3. Cierra VISO completamente antes de compilar

PROBLEMA: "Sigue siendo lento"
────────────────────────────────
✓ La DLL puede no estar siendo usada
✓ Solución:
  1. Ejecuta: python test_inventory_optimizer.py
  2. Verifica que diga: "✅ InventoryOptimizer.dll cargada"
  3. Si dice "⚠️ Usando fallback", recompila
