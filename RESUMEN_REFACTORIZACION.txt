## 🏗️ Patrones Implementados

### 1. **Strategy Pattern**
Cada plantilla es una estrategia intercambiable
```python
generador = GeneradorBoletasPlantilla(usuario_id)
# Automáticamente selecciona la estrategia (plantilla)
generador.generar_boleta(datos)
```

### 2. **Template Method Pattern**
Métodos comunes en la clase base
```python
class PlantillaBase(ABC):
    def generar(self):  # Abstracto - implementado en subclases
        ...
    
    def _limpiar_texto(self):  # Común para todas
        ...
```

### 3. **Factory Pattern**
Creación dinámica de plantillas
```python
PLANTILLAS_DISPONIBLES = {
    'pequeña': PlantillaPequena,
    'a4': PlantillaA4,
}
```

## 💡 Características Clave

### PlantillaBase
- Clase abstracta que define interfaz común
- Métodos reutilizables: `_guardar_pdf()`, `_insertar_logo()`, etc.
- Manejo centralizado de errores
- Funciones de formato: `_format_moneda()`, `_obtener_timestamp()`

### Plantillas Específicas
- Herdan de PlantillaBase
- Implementan método `generar()`
- Cargan su propia `CONFIGURACION`
- Métodos privados para dibujar secciones

### Módulo GUI
- `PanelPlantillas`: Widget para seleccionar plantilla
- `PlantillaCard`: Tarjeta individual con interfaz
- `PanelLogo`: Widget para gestionar logo empresa
- Totalmente independiente y reutilizable

## 🎓 Cómo Usar

### Opción 1: Generar Boleta Simple
```python

generador = GeneradorBoletasPlantilla(usuario_id='123')
ruta_pdf = generador.generar_boleta(datos_boleta)
```
