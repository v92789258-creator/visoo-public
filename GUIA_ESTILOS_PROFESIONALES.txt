GUÍA DE APLICACIÓN DE ESTILOS PROFESIONALES
==============================================

ARCHIVO CREADO:
✅ gui/styles/appointments_professional_style.py

CÓMO USAR:
===========

1. En appointments_page.py, añadir al inicio:

    from gui.styles.appointments_professional_style import (
        APPOINTMENTS_PAGE_STYLE,
        COLORS
    )

2. En la clase AppointmentsPage.__init__(), reemplazar todo el setStyleSheet() con:

    self.setStyleSheet(APPOINTMENTS_PAGE_STYLE)

3. Actualizar los nombres de elementos para usar Object Names:

    left_panel.setObjectName("left_panel")
    calendar_title.setObjectName("calendar_title")
    add_appointment_btn.setObjectName("btn_new_appointment")
    etc...

CAMBIOS PRINCIPALES EN EL DISEÑO:
==================================

❌ ANTES (Feo):
- Colores muy brillantes (#0078D4, #4CAF50, #FF9800)
- Gradientes coloridos
- Emojis excesivos
- Animaciones lentas
- Bordes redondeados excesivos
- Fuentes inconsistentes

✅ AHORA (Profesional):
- Paleta corporativa: Azul oscuro (#0d47a1), grises, blancos
- Diseño minimalista y limpio
- Emojis solo donde necesario (no decorativos)
- Sin animaciones innecesarias
- Bordes redondeados sutiles (6px)
- Tipografía profesional (Segoe UI, Helvetica Neue)

ESTRUCTURA DE APLICACIÓN:
===========================

1. Aplicar setStyleSheet() global a toda la página:
   
   self.setStyleSheet(APPOINTMENTS_PAGE_STYLE)

2. Asignar Object Names a cada elemento:
   
   elemento.setObjectName("nombre_identificador")

3. Los estilos se aplican automáticamente según el Object Name

4. Para elementos dinámicos, usar setStyleSheet() individual:
   
   btn_edit.setObjectName("btn_edit_appointment")


REFERENCIAS DE OBJECT NAMES:
=============================

Paneles:
  - "left_panel"              (Panel izquierdo con calendario)
  - "appointment_details"     (Panel derecho con detalles)

Títulos:
  - "calendar_title"          (Título del calendario)
  - "calendar_subtitle"       (Subtítulo)
  - "appointment_title"       (Título de detalles)

Botones principales:
  - "btn_new_appointment"     (Botón Nueva Cita)
  - "btn_statistics"          (Botón Estadísticas)

Botones de acción (en tarjetas):
  - "btn_edit_appointment"    (Editar)
  - "btn_complete_appointment" (Completar)
  - "btn_cancel_appointment"  (Cancelar)

Tarjetas:
  - "appointment_card"        (Tarjeta normal)
  - "appointment_card_past"   (Tarjeta fecha pasada)

Elementos de tarjeta:
  - "appointment_time"        (Hora de la cita)
  - "appointment_patient_name" (Nombre del paciente)
  - "appointment_type"        (Tipo de cita)

Estados:
  - "appointment_status_completed"  (Completada - verde)
  - "appointment_status_pending"    (Pendiente - naranja)
  - "appointment_status_past"       (Vencida - rojo)

Otros:
  - "separator"               (Líneas divisoras)
  - "no_appointments_message" (Mensaje sin citas)

    }

Los cambios se aplicarán a toda la aplicación automáticamente.
